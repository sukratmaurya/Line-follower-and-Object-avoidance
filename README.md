# Line-follower-and-Object-avoidance
This project is a hybrid autonomous robot using Arduino that combines line following and real-time obstacle detection. It tracks a predefined path with IR sensors and overrides navigation when an obstacle is detected within a set distance. The system showcases multi-sensor integration, embedded C programming, and real-time motor control.
